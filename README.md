# BIT

Обычный агент командной строки с функцией голосового ввода. В нем я пытаюсь представить кодовую основу для таких же одиночек самоучек как я для создания их собственного ИИ агента. В BIT я стараюсь сделать модульную архитектуру и свести всю настройку в пару файлов простого формата. По своей сути это персональный агент на минималках для тех кто хочет посмотреть как вообще примерно устроен тот же самый OpenClaw в максимально упрощенном виде и в будущем еще и полностью настраиваемый под себя. 

## Планы
В скором времени будет добавлен пользовательский интерфейс на QT Widgets, его я буду развивать как отдельную ветку, тоже самое могу сказать про модульную версию для администрирования нескольких серверов/виртуалок из единого интерфейса. В совсем далеких плнах у меня расширить совместимость и, если у меня хватит знаний сил и контекстного окна модели добавлю поддержку для Windows. В ближайших планах выкатить версию серверную для управления умным домом по схеме самодельная колонка -> BIT на сервере домашнем -> действие в доме/вызов API музыкального сервиса локального/действие на компьютере -> ответ / отчет. Именно поэтому я рад любым форкам или совместной работе. Можете найти меня в тиктоке @hacktheworld50 или в телеграмме @hacktheworld123

Если ктото хочет поработать со мной, неважно с какм стеком- буду только рад.
В долгосрочных планах у меня добавить UI на QT и разумеется расширить функционал ( пока из него только взаимодействие с командной строкой). Тестировал я его пока только на системе из ноута из 2010 года на Debian 13 с Plasma и своей домашней виртуалки с P102-100. Доступа ко всем файлам BIT не имеет, только к своей папке. Ограничения на выполнение команд он не имеет, система полагается на подтверждение действий пользователем, логирование идет в текстовый файл с временной меткой, инструментом, его параметрами и его выводом. Все вызванные команды отображаются в вашем терминале (знаю, над удобством еще много рабоать). Есть возможность обновления через команду /update. В разработке мне помогает автодополнение и разумеется бесплатная версия DeepSeek и Gemini, тк как уровень владения языком у меня низкий, но код все же продолжаю писать от руки, так как в процессе этого часто концепт меняется несколько раз. Лично мне кажется что это (в конечном итоге)скорее кодовая база для ваших личных проектов.
